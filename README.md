## 📺 Project Overview

EduPixels is an innovative web platform that leverages Artificial Intelligence to generate fully structured educational courses from a simple text prompt. It provides a complete learning environment with interactive content, an AI Assistant for real-time support, and an automated grading system.

## ✨ Key Features

*   **Prompt-to-Course Generation**: Instantly build modules and lessons based on any topic using Google Gemini AI.
*   **Interactive Workspace**: Clean, distraction-free environment for consuming content.
*   **Smart AI Assistant**: A persistent chat companion that understands the context of the current lesson and helps with complex topics.
*   **Automated Homework Grading**: Get instant feedback and grades for submitted assignments via AI review.
*   **Progress Tracking**: Intuitive visual indicators for lesson completion and course advancement.

---

## 🛠 Tech Stack

### Frontend
- **Framework**: React 19 + Vite
- **Styling**: TailwindCSS & Custom Pixel styles
- **Icons**: Phosphor Icons
- **Logic**: Context API, React Router, Highlight.js for code snippets.

### Backend
- **Framework**: Django 5.2 + Django REST Framework (DRF)
- **AI Engine**: Google Generative AI (Gemini API)
- **Auth**: SimpleJWT (JWT Authentication)
- **Database**: SQLite (Development)

---

## 🚀 Technical Highlights (Frontend)

The Frontend, developed by **Serhiy Hodis**, features several complex implementations:
- **Context-Aware AI Assistant**: Implementation of a selection-based tooltip that allows users to ask questions about specific parts of the lesson text.
- **Dynamic Markdown Rendering**: Seamless integration of Markdown content with syntax highlighting that persists through React's re-render cycles.
- **Scroll-Synchronized Progress**: A robust tracking system that updates the user's progress in real-time as they read through the material.
